# OrBase-File-Associater
This is a program called OrBase. It lets you link files by using 2 new file types: .orb and .orun files. .orb files maintain the code and .orun files run them as batch files! Make sure you have Visual Studio Code installed, or the default settings will not work. 
NOTE: orb.ico is the icon, completely optional but requested for a better use. You can change what .orb files open instead of Visual Studio Code in settings. MAKE SURE YOU HAVE A FOLDER NAMED "Orbs" WITH orb.ico IN IT BEFORE INSTALLING. RUN AS ADMIN.
If virustotal or your antivirus flags installer and uninstaller as malware, its very common because you are required to touch registry and add stuff to it to create new file types, you can see the code by yourself or run them as .py files, we are completely open-source.
