OrBase File Associater

orbase adds two file types to windows, a .orb that has code and .orun that runs it. you write something in a .orb, tell the language on the first line, then run the matching .orun to run it. i made it for fun.

Installer Github

your code is in a .orb file. the .orun with the same name runs it, so cool.orun runs cool.orb. the first line of the .orb tells the .orun what language it is. if it doesnt have a matching name or a language it doesnt run. No set language defaults to batch.

hello.orb
--lang: python
print("hello world")

when you run a .orun, orbase copies your code to the temp folder, runs it with the language you picked, then deletes the copy. the two file types are registered in the registry as progid entries, the same way every other file type on windows. .orb files open in vs code by default, and you can change that under default apps if you want something else.

theres twelve languages built in batch, python, powershell, javascript, ruby, perl, php, java, lua, go, rust and r. you only need the ones you actually use, and if you pick one thats not installed orbase points you to where to download it. compiled ones like go, rust and java work the same as the rest. if your language doesnt exist make an issue.

to set it up you run OrBaseInstaller.pyw it writes the .orb and .orun entries into the registry, it doesnt use bg tasks. when you want to uninstall it run OrBaseUninstaller.pyw removes the associations and file types. youll need windows 10 or 11 and admin rights for the one time it writes to the registry.

one thing, because the installer edits the registry and isnt code signed some antivirus tools flag it as a pua. its a false positive and this warning pops up cuz the installer touches registry. the full source is on github if you want to read it before running anything.

orbase is free and open source. code is at github. .orb, .orun
